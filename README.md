# DevPulse Cloud Infrastructure

A responsive landing page for cloud infrastructure, DevPulse shows pricing plans, subscription features, and an API registration form.

## Features

- Latency Tracking
- Auto-Remediation
- Log Aggregation

## Pricing Plans

- Developer
- Pro Cluster
- Enterprise Dedicated

## API Registration

Users can input their name, email address, and the number of API calls they would want to receive per minute on the API registration form. It makes use of HTML form validation built in.

## How to Run

1. First, this repository can be downloaded or cloned.
2. Second,go into the project folder.
3. Lastly, launch a web browser and open index.html.
